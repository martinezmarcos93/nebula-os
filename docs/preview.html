Nébula OS · Cosmic Dark

Simulación interactiva del escritorio: gestor bspwm sobre Xorg, panel lateral por categorías, barra de sistema estilo polybar y lanzador rofi. Paleta, tipografías y taxonomía tomadas literalmente de dotfiles/nebula/colors.sh y categories.toml.

No es una captura real ni una VM: es una maqueta de navegador para ver la dirección visual y el flujo.
